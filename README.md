# mailerlm

A small mailing-list and campaign tool for an author. Public code; all data (contacts, consent, replies, campaigns, keys) stays in a private workspace outside this repository.

## What it does

Lists and contacts, campaigns written in Markdown with their own values, images and sender, editable frame templates, and a web app (served on the owner's tailnet) to manage all of it. Everything the owner types lives in a private database outside this repository; the repository holds code, prompts and starter templates only.

Install and commands: see `CLAUDE.md`. Design decisions live in each package's docstring and in `docs/generated/`.
